# PropriaClick

## 关于软件

PropriaClick 是**便携的辅助工具软件**，提供通过 `Ctrl + 右键单击` 直接打开目标属性的功能。
作者为 42，联系方式为 42_ans@proton.me 或 42ans.com。

运行要求 `Windows 10/11 x64` 和 `.NET Framework 4.x`（通常系统自带）。
exe 文件即软件本体，允许直接复制或移动，无需安装，也不写入注册表。

## 使用方式

构建方法见 `BUILDING.md`。

运行软件后，对桌面或文件资源管理器中的图标 `Ctrl + 右键单击` 即可打开目标属性界面（若可能）。
文件资源管理器左侧导航栏中的项目同样适用。
失败则回退为无效。

只拦截带 `Ctrl` 的右键，不带 `Ctrl` 的右键仍为系统默认菜单。

软件显示为系统托盘图标，可以在右键弹出操作栏。
- 隐藏：隐藏软件的系统托盘图标，软件继续在后台运行，可以通过再次运行软件重新显示
- 关闭：关闭软件
- 说明：在软件目录中创建包含软件信息的 markdown 文件并打开
- 许可证：在软件目录中创建包含软件许可证的文件并打开

## 目录说明

软件无需安装、不会添加开机启动或写入注册表，仅在自身目录中使用或创建以下文件。

| 文件 | 说明 |
| --- | --- |
| `PropriaClick.exe` | 软件本体，可直接复制或移动 |
| `PropriaClick.log` | 运行日志。启动时创建，只记录启动与错误信息，正常使用时不会有新内容 |
| `PropriaClick-About.md` | 由**说明**菜单项创建，每次点击都会重新生成或覆盖，可随时删除 |
| `PropriaClick-License.txt` | 软件许可证原文，由**许可证**菜单项创建，每次点击都会重新生成或覆盖，可随时删除 |

若软件所在目录不可写（例如放在系统保护目录中），日志与上述文档会改为写入系统临时目录 `%TEMP%`。
除此之外，软件不会创建、修改或删除任何其他文件，不会访问网络。
